# Routes

This project uses **TanStack Router** file-based routing with Vite. Every `.tsx` file in this directory
is a route. The root layout is `src/routes/__root.tsx`.

## Conventions

| File                       | URL                                                                                     |
| -------------------------- | --------------------------------------------------------------------------------------- |
| `index.tsx`                | `/`                                                                                     |
| `admin.tsx`                | `/admin`                                                                                |
| `_site.about.index.tsx`    | `/about`                                                                                |
| `_site.services.$slug.tsx` | `/services/:slug`                                                                       |
| `_site.careers.tsx`        | `/careers`                                                                              |
| `_site.blog.tsx`           | `/blog`                                                                                 |
| `_site.contact.tsx`        | `/contact`                                                                              |
| `__root.tsx`               | app shell — wraps every page with QueryClient & ContentProvider; preserves `<Outlet />` |

`routeTree.gen.ts` is auto-generated by the TanStack Router Vite plugin.
